# Simulation
Very basic particle simulator. I aim to simulate particles in gravitational fields, both Newtonian and Einsteinian.

# About
I am building everything from the basics and I am not very good at coding so this is will be a good way to learn more about it. I have also chosen Python because that is the language I know the most. All the animations will be done through matplotlib and will be rendered after the fact. I plan on simulating using Euler's method and Runge-Kutta 4. This simulation will also test the viability of these different methods.

# Goals

Build a particle system to simulate point particles in Newtonian gravity. This will involve the two body and the many body problems.
Next I aim to add charged particles and simulate them with the gravitational fields to see how they interact in the Newtonian setting.
Then I want to move to the Einstein gravity case with the Schwarzchild black hole and I want to simulate how massless and massive particles move around these black holes.
